# LaunchDarkly AI Recommendations Integration

This folder contains drop-in code to add AI-powered book recommendations to the AnyCompanyRead app generated by the AWS AI-DLC workshop. Model and prompt are controlled at runtime by a LaunchDarkly AI Config.

## What's Included

```
integration-code/
├── packages/
│   ├── backend/src/handlers/
│   │   └── recommendations-handler.ts    # Lambda (Node 20, Bedrock Converse)
│   ├── frontend/src/components/
│   │   └── RecommendationsSection.tsx    # React + Cloudscape component
│   ├── shared/src/types/
│   │   └── recommendations.ts            # Shared TypeScript types
│   └── cdk/lib/constructs/
│       └── recommendations-construct.ts  # CDK construct (Lambda + API + IAM)
├── test/                                 # Standalone test harness
└── INTEGRATION.md                        # This file
```

## How It Works

```
User visits catalog
       │
       ▼
RecommendationsSection (React)
       │  GET /recommendations  (Cognito-authorized)
       ▼
recommendations-handler (Lambda, Node 20)
       │
       ├─► LaunchDarkly AI Config "book-recommendations"
       │       returns model, system prompt, temperature, maxRecommendations
       │
       ├─► DynamoDB: Orders (user history), Books (catalog)
       │
       └─► Bedrock Converse API (Claude Sonnet or Opus, per variation)
                ↓
        tracker.trackBedrockConverseMetrics → AI Config dashboard metrics
```

## Integration Steps

### 1. Copy the Files

```bash
# From the workshop root (anycompanyread project), with this repo at $LD_INTEG:
cp $LD_INTEG/packages/backend/src/handlers/recommendations-handler.ts \
   packages/backend/src/handlers/

cp $LD_INTEG/packages/frontend/src/components/RecommendationsSection.tsx \
   packages/frontend/src/components/

cp $LD_INTEG/packages/shared/src/types/recommendations.ts \
   packages/shared/src/types/

cp $LD_INTEG/packages/cdk/lib/constructs/recommendations-construct.ts \
   packages/cdk/lib/constructs/
```

### 2. Wire Up the CDK Stack

In `packages/cdk/lib/anycompanyread-stack.ts` (the stack the agent generates):

```typescript
import { RecommendationsConstruct } from './constructs/recommendations-construct';

// After the API Gateway and tables exist:
new RecommendationsConstruct(this, 'Recommendations', {
  api: apiConstruct.api,
  authorizer: apiConstruct.authorizer,
  ordersTable: dataConstruct.ordersTable,
  booksTable: dataConstruct.booksTable,
});
```

### 3. Mount the Frontend Component

In `packages/frontend/src/pages/CatalogPage.tsx` (or whichever page the agent generated for the catalog):

```tsx
import { RecommendationsSection } from '../components/RecommendationsSection';

// Above or below the book list:
<RecommendationsSection />
```

> The frontend reads `VITE_API_BASE_URL` (Vite) by default. If the generated app reads its API URL from `config.json` (the new workshop pattern), import that hook instead of `import.meta.env`.

### 4. Store the LaunchDarkly SDK Key

```bash
aws ssm put-parameter \
  --name "/anycompanyread/launchdarkly/sdk-key" \
  --value "sdk-YOUR-SDK-KEY" \
  --type SecureString
```

The Lambda reads `process.env.LAUNCHDARKLY_SDK_KEY` first, then falls back to SSM, so you can also set it directly on the Lambda for local testing.

## LaunchDarkly Setup

### Create the AI Config

**Key:** `book-recommendations` &nbsp;&nbsp; **Mode:** Completion

| Variation key | Model ID | Temperature | Custom: `maxRecommendations` | System prompt |
|---|---|---|---|---|
| `safe-sonnet` | `us.anthropic.claude-3-5-sonnet-20241022-v2:0` | 0.2 | 3 | "You are a book recommendation assistant for a mainstream bookstore. Recommend BESTSELLERS ONLY. Stay in the SAME GENRE. Make OBVIOUS CONNECTIONS." |
| `adventurous-opus` | `us.anthropic.claude-opus-4-20250514-v1:0` | 0.95 | 5 | "You are a literary explorer. Recommend HIDDEN GEMS - cult classics, international literature. Make TANGENTIAL CONNECTIONS. AVOID bestsellers." |

Set the default rule to serve `safe-sonnet`.

### Demo Script

1. Open the deployed app → "Recommended for You" section shows 3 mainstream books and a "Powered by Claude Sonnet" badge.
2. In LaunchDarkly: AI Configs → `book-recommendations` → Targeting → change default to `adventurous-opus`. Save.
3. Refresh the app → 5 hidden-gem recommendations appear, badge now says "Powered by Claude Opus".
4. Point at the dashboard → tracker metrics (latency, token usage) populated automatically.

No redeploy.

## Troubleshooting

**Recommendations not loading**
- Browser console: 401 → Cognito token missing/expired. Re-login.
- Browser console: 5xx → check CloudWatch logs for the Recommendations Lambda.

**"SDK key not found"**
```bash
aws ssm get-parameter --name "/anycompanyread/launchdarkly/sdk-key" --with-decryption
```

**Model not switching after toggle**
- Confirm AI Config key is exactly `book-recommendations`.
- Confirm the variation has `enabled: true` and a valid model ID.
- LaunchDarkly streams updates; if the Lambda is cold, the first invocation may hit defaults — invoke twice.

**`AccessDeniedException` from Bedrock**
- Ensure the AWS account has model access enabled for both Sonnet 3.5 and Opus 4 in the deployment region.
- Check the construct's IAM policy includes `arn:aws:bedrock:*::foundation-model/*` and `arn:aws:bedrock:<region>:<account>:inference-profile/*` (inference profiles are required for the `us.*` model IDs).
